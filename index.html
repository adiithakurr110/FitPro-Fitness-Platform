Developer Quickstart

How to Run the Full Java Backend Locally

FitPro includes a zero-config embedded H2 database and cargo Tomcat runner.

bash — FitPro Local Setup & Execution
# 1. Clone the repository
git clone https://github.com/adiithakurr110/FitPro-Fitness-Platform.git
cd FitPro-Fitness-Platform/fitpro

# 2. Run the 32 Automated JUnit Tests
mvn test

# 3. Launch the Java Web Application (Tomcat 9 automatically downloads)
mvn package cargo:run
# Open in your browser: http://localhost:8080/fitpro/

# 4. Launch the Java Swing Desktop Admin GUI
mvn compile exec:java
# Or simply double-click run-gui.bat on Windows!
