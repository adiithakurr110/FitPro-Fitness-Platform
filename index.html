Deployment Separation

Dual-Deployment Architecture

FitPro separates static product presentation from live enterprise Java execution.

Static Showcase (Vercel)

Edge CDN Deployment

Deployed on Vercel as a zero-dependency static site. Hosts this interactive architecture overview, feature showcases, client-side BMI calculator, and slide deck documentation.

vercel.json: cleanUrls: true, framework: null

Full Java Web App (Tomcat)

Enterprise WAR Container

Runs the complete Java backend: 7 Servlets, JSP rendering, JDBC persistence (H2/MySQL), multithreaded notifications, and salted PBKDF2 authentication.

mvn package cargo:run → http://localhost:8080/fitpro/
